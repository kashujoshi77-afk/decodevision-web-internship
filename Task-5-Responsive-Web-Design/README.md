
# Task 5 – Responsive Web Design

## Overview

As part of my Decode Vision Web Development Internship, I created and tested responsive web projects using HTML, CSS, and JavaScript.

The projects were designed to provide a smooth user experience across different screen sizes, including desktop, laptop, tablet, and mobile devices.

## Responsive Projects

### 1. Personal Portfolio Website
- Responsive navigation bar
- Responsive hero section
- Responsive About, Skills, Services, and Projects sections
- Responsive Contact Form
- Responsive Footer
- Mobile-friendly layout

### 2. To-Do List Application
- Responsive task cards
- Responsive input and filter sections
- Mobile-friendly layout
- Dark/Light Mode

### 3. Digital Calculator
- Responsive calculator interface
- Mobile-friendly buttons and display

### 4. Digital Clock
- Responsive clock display
- Mobile and desktop compatibility

### 5. Image Slider
- Responsive image display
- Mobile-friendly navigation

### 6. Form Validation
- Responsive form layout
- Mobile-friendly input fields
- JavaScript form validation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Testing

All projects were tested on different screen sizes, including:

- Desktop
- Laptop
- Mobile

The layouts were checked to ensure that the content, buttons, navigation, forms, and other components remain usable and visually accessible on different screen sizes.

## Conclusion

This task helped me understand the importance of responsive web design and how HTML, CSS, and JavaScript can be used together to create user-friendly websites and web applications that work across different devices.
